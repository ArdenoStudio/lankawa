Comprehensive API Landscape for Sri Lanka — News, Government, Finance, Telecom, and Developer Ecosystem
Executive Summary
Sri Lanka's API ecosystem spans seven distinct layers: global news aggregators with country filtering, unofficial but production-ready Sinhala news scrapers, CKAN-based open data, a unified census and election data abstraction, financial and banking platforms, telecom network APIs under GSMA Open Gateway, and a rich long tail of location, weather, and niche developer repositories. The most immediately usable news layer consists of 15 monitored Sri Lankan sources via World News API and free Vercel-hosted endpoints for Hiru News and Esana [1](https://worldnewsapi.com/docs/news-sources/sri-lanka-news-api/) [2](https://github.com/tharustack/Hiru-News-API) [3](https://github.com/ThaminduDisnaZ/Esena-News-API-Sinhala-News-API). Government data is anchored by the CKAN Action API on data.gov.lk and the community-built lanka_data abstraction that exposes census, election, and survey data through a single command language [4](https://github.com/nuuuwan/lanka_data). Finance and payments are led by the unofficial Colombo Stock Exchange REST surface at https://www.cse.lk/api/ [5](https://github.com/GH0STH4CKER/Colombo-Stock-Exchange-CSE-API-Documentation) and by PayHere, Sampath Bank's standardised API banking, and LankaPay JustPay. Telecom is the most mature federated layer, with four operators exposing OTP Validation, Device Location, and Carrier Billing through GSMA Open Gateway [6](https://www.gsma.com/newsroom/press-release/sri-lankas-four-mobile-operators-commercially-launch-country-wide-network-apis-through-gsma-open-gateway-initiative-achieving-100-country-coverage/).

1.2 Sri Lanka-Specific News APIs (Unofficial, Community-Built)
These are reverse-engineered scrapers deployed on Vercel, widely used in production by local developers.
Hiru News API — production-ready REST API for hirunews.lk, Sri Lanka's most visited news site [2](https://github.com/tharustack/Hiru-News-API).
Live: https://hirunews.vercel.app/api
Endpoints: /api/health, /api/breaking-news, /api/latest-news?limit=10, /api/article/{id}, /api/category/{sports|business|entertainment|general}, /api/date?date=YYYY-MM-DD, /api/search?q=term
Features: full-text extraction, thumbnails, images, word count, Sinhala/English
Auth: none, CORS enabled
Esana News API (Helakuru Esana) — fast proxy for Helakuru Esana JSON endpoint [3](https://github.com/ThaminduDisnaZ/Esena-News-API-Sinhala-News-API).
Live: https://esena-news-api-v3.vercel.app/
Alternate: https://esana-api.vercel.app/ [8](https://github.com/Damantha126/Helakuru-Esana-API)
Returns news_data.data[] with titleSi, titleEn, contentSi[], thumb, cover, published, share_url
Ada Derana News API — https://ada-derana-news-api.vercel.app/ documented on GitHub as latest news retrieval [9](https://github.com/nbdev-sl/AdaDerana-News-API).
Other scrapers: Helakuru-Esana-API (Damantha126), Esana GitHub Bot variants, NewsFirst.lk scrapers listed under srilanka topic on GitHub.
2. Government Open Data and Official Statistics APIs
2.1 National Open Data Portal — data.gov.lk
Sri Lanka's portal runs on CKAN, exposing the standard Action API.
Portal: http://www.data.gov.lk listed as official open government site [10](https://en.wikipedia.org/wiki/List_of_open_government_data_sites)
CKAN Action API base: https://data.gov.lk/api/3/action/
Key actions:package_list — list datasets
package_search?q=...&rows=10 — search
package_show?id=dataset-name — metadata
datastore_search?resource_id=... — query CSV resources hosted in DataStore
group_list, tag_list, organization_list
Pattern identical to Data.gov CKAN API described at CKAN features [11](http://ckan.org/features/api)
Health Ministry mirror: https://data.health.gov.lk uses same CKAN stack.
Limitations: portal suffers from stale datasets (noted up to 2012 in critiques) but CKAN API itself is functional.
2.2 Lanka Data — Unified Interface
Community project by @nuuuwan that implements "one API to rule them all" [4](https://github.com/nuuuwan/lanka_data).
Install: pip install lanka-data
Code: from lanka_data import CommandRunner; CommandRunner.run("Religion/2024/LK/Map")
HTTP via Vercel: https://lanka-data-phi.vercel.app/Religion/2024/LK/Map [4](https://github.com/nuuuwan/lanka_data)
Sources integrated: Census of Population and Housing 2012 & 2024, Election Commission, Lanka Data, Survey Department [4](https://github.com/nuuuwan/lanka_data)
Command syntax: <Topic>/<Year>/<Region>:<Granularity>/<Visualization>:<Stat> e.g. Empty/2024/LK:province/Map, Religion/2012-2024/LK:district/Map:1st
Outputs: PNG/SVG maps, JSON data, BarCharts.
2.3 World Bank API for Sri Lanka
Base: https://api.worldbank.org/v2/
Country code: LKA (ISO3) / LK (ISO2) [12](https://databank.worldbank.org/metadataglossary/gender-statistics/country/LKA)
Examples:https://api.worldbank.org/v2/country/LKA/indicator/NY.GDP.MKTP.CD?format=json — GDP
https://api.worldbank.org/v2/country/LKA/indicator/SP.POP.TOTL?format=json — population
Aggregate queries supported for regions and income groups [13](https://datahelpdesk.worldbank.org/knowledgebase/articles/898614-aggregate-api-queries)
2.4 Other Government Data Surfaces
Parliament, Election Commission: No official API, but scraped via lanka_data and via GitHub projects nuuuwan/elections, places_lk.
Survey Department: Boundary files used by lanka_data and places_lk.
Sri Lanka Document Datasets: 26 datasets (gazettes, court judgements, parliamentary debates) aggregated on GitHub for LLM research.
3. Financial, Exchange, and Stock Market APIs
3.1 Colombo Stock Exchange (CSE)
No official public docs; community reverse-engineered.
Base: https://www.cse.lk/api/ [5](https://github.com/GH0STH4CKER/Colombo-Stock-Exchange-CSE-API-Documentation)
Endpoints (POST):companyInfoSummery (symbol e.g. LOLC.N0000)
tradeSummary, todaySharePrice, topGainers, topLooses, mostActiveTrades
marketStatus, marketSummery, aspiData, snpData, chartData, allSectors, dailyMarketSummery
MCP Servers: cse-market-mcp-server exposes ASPI, S&P SL20 with TradingView indicators.
3.2 Central Bank of Sri Lanka (CBSL)
Human page: https://www.cbsl.gov.lk/cbsl_custom/param/ratewindow.php lists daily TT buying/selling [14](https://www.cbsl.gov.lk/cbsl_custom/param/ratewindow.php)
No official JSON API; developers scrape:https://www.cbsl.gov.lk/en/exchange-rates for indicative rates
Historical rates via https://www.cbsl.gov.lk/en/search/node/daily%20exchange%20rate [15](https://www.cbsl.gov.lk/en/search/node/daily%20exchange%20rate)
Community wrapper: LankaRates.com aggregates CBSL sources with timestamps.
3.3 Currency Conversion with LKR Support
Currencylayer (apilayer) — 168 currencies, LKR supported, free 100 req/mo, &currencies=LKR [16](https://github.com/apilayer/currencylayer-API)
Exchangerate.host, ExchangeRate-API, Open Exchange Rates — all include LKR.
Wise, XE — provide mid-market LKR but not free API for bulk.
3.4 Banking API Platforms
Sampath Bank Standardised API Banking — first in Sri Lanka [17](https://www.ft.lk/financial-services/Sampath-Bank-pioneers-SL-s-standardised-API-banking-platform-redefining-transaction-banking/42-777823) [18](https://ceylontoday.lk/2025/06/19/sampath-bank-launches-sri-lankas-first-standardised-api-platform/).
Capabilities: transaction banking, corporate ERP integration (CDB onboarded first) [19](https://www.ft.lk/financial-services/Sampath-Bank-rolls-out-API-Banking-with-CDB-as-first-corporate-onboarding/42-780607), real-time payments, Visa Cybersource integration.
Access: enterprise onboarding via Transaction Banking division.
Other Banks: Commercial Bank, Seylan, HNB expose private APIs via LankaPay JustPay integration, not public docs.

5. Transport, Tourism, and Logistics APIs
5.1 Railways
Sri Lanka Railways Location API — Node.js + MongoDB, ingests GPS, 90-day retention [22](https://github.com/A-Samod/sri-lanka-railways-location-api)Endpoints: POST /location, GET /location/:trainId, GET /location/history/:trainId
Simulator repo sends data at 1-min intervals.
Official Schedule: https://eservices.railway.gov.lk/schedule/searchTrain.action (web search, no API)
Seat Reservation: https://seatreservation.railway.gov.lk — web only.
5.2 Mobility / Ride-Hailing
PickMe — Sri Lankan super-app (taxi, food) [23](https://en.wikipedia.org/wiki/PickMe). No public rider API, but Standard Chartered built country's first interbank instant payment API for PickMe collections [24](https://www.ft.lk/Financial-Services/Standard-Chartered-offers-unique-API-connectivity-solution-for-PickMe-payments/42-718687). Enterprise integration via PickMe Business.
5.3 Tourism and Hospitality
PearlPath API — backend for Sri Lanka Smart Travel Platform (Node, Express, Supabase) [25](https://github.com/PearlPath/pearlpath-api)
Global OTAs with Sri Lanka inventory via affiliate APIs: Booking.com, Agoda, Traveloka, Viator — use standard affiliate programs, filtering country=lk or city=Colombo.
6. Location, Administrative, and Postal Code APIs
6.1 Comprehensive Location APIs
SLCities.live API — most complete modern API [26](https://github.com/dinethsiriwardana/Sri-Lanka-Location-Details)
Prod: https://slcities.live/api
Docs: https://slcities.live/api-docs (Swagger UI), https://slcities.live/api-spec (OpenAPI 3.1)
Endpoints:GET /cities, /cities/district/{districtName}, /cities/province/{provinceName}, /cities/postcode/{postcode}, /cities/search?q=&lang=, /cities/nearby?lat=&lon=&radius=
GET /provinces, GET /districts, GET /districts/province/{provinceId}, GET /districts/province-name/{provinceName}
GET /summary
Source: madurapa's repository.
Location API SL (PasinduS96) — Heroku hosted [27](https://github.com/PasinduS96/location-api-sl)
Base: https://locatesrilanka.herokuapp.com/
Endpoints: /cities, /provinces, /districts, /cities/cordinates/{CITY}, /cities/byDistrict/{ID}, /cities/colombo_mca, /districts/byprovince/{ID}
GPS for major cities and sub areas.
Raw Datasets:

madurapa/sri-lanka-provinces-districts-cities — JSON/SQL with postal codes, lat/lon, Sinhala/Tamil names.
places_lk (nuuuwan) — Python lib returning lat/lon for Sri Lankan places.
shahmy/sri_lanka_administrative_boundaries — Laravel seeder for Provinces, Districts, DS Divisions, GN Divisions.

APIs via location APIs above; dedicated postal APIs return JSON via postcode search.

8. Payments, Fintech, and LankaPay Rails
8.1 LankaPay National Switch
CEFTS (Common Electronic Fund Transfer Switch) — real-time interbank.
JustPay — platform built on CEFTS linking bank accounts to apps, launched 2018 [34](https://www.lightspark.com/knowledge/instant-payments-sri-lanka)
JustPay Web: checkout for e-commerce, device-compatible [35](https://lankapay.net/en/for-financial/justpay)
Integration via bank: bank registers @handle mapper; no direct public API docs, bank-mediated.
Use cases: Q+ app multi-bank via JustPay, HNB Pay by Bank Account via JustPay Web.
LANKAQR — 400k+ merchants, interoperable QR.
8.2 PayHere — Authorized Payment Aggregator
Only CBSL-authorized aggregator accepting Visa, Mastercard, Amex, Discover, Frimi, Genie, eZ Cash, mCash, Sampath Vishwa [36](https://www.ft.lk/Financial-Services/PayHere-processes-Rs-1-b-online-payments-for-local-businesses/42-706975).
Docs: [https://support.payhere.lk/api-&-mobile-sdk/](https://support.payhere.lk/api-&-mobile-sdk/)
APIs: Checkout API, Recurring API, Preapproval API, Charging API, Retrieval API, Subscription Manager API (list/ retry/ cancel) [37](https://www.dasun.dev/docs/laravel-payhere/api/subscription-manager-api.html), Refund API, Authorize API, Capture API
SDKs: PayHereLK/payhere-mobilesdk-reactnative, Laravel wrapper Visanduma/laravel-payhere [38](https://github.com/Visanduma/laravel-payhere), Node, Python unofficial SDKs.
Currencies: LKR, USD, GBP, EUR, AUD [39](https://blog.payhere.lk/the-one-stop-shop-for-your-onboarding-process-payhere/)
8.3 WEBXPAY
Stack: XGATEWAY (e-commerce APIs), XPOS, XSPLIT (installments), XQR (LankaQR), XPAYLINK, XSUPPLIER, XCOLLECTOR [40](https://www.dailymirror.lk/business-news/WEBXPAYs-rebrand-turns-every-transaction-into-greater-value/273-313817)

12. Implementation Recommendations
For News App: Start with Hiru News API for Sinhala breaking news (no key, <5s latency) plus World News API for English multi-source aggregation with source-country=lk. Add GNews as fallback for category filtering.
For Gov Dashboard: Use lanka_data HTTP endpoint for rapid prototyping of demographic maps, and fall back to data.gov.lk CKAN package_search + datastore_search for tabular open data. For economic indicators, World Bank API is most stable.
For Fintech: Integrate PayHere Checkout + Subscription Manager for card/wallet collection; integrate Sampath API Banking for corporate payouts; for carrier billing, onboard via IdeaBiz and GSMA Open Gateway to reach all 4 telcos.
For Logistics: Combine SLCities API nearby search with PickMe Business for last-mile; use Sri Lanka Railways Location API for train ETA if building multimodal planner.

Exhaustive API Catalogue for Sri Lanka — Every Sector, Official and Community
Executive Summary
This report expands the initial 50-API catalogue to more than 120 distinct endpoints that touch Sri Lanka, organized into 16 sectors. No single government API gateway exists; the ecosystem is federated across CKAN open data at data.gov.lk/api/3/action/, community abstractions by @nuuuwan, telecom federation via GSMA Open Gateway achieving 100 percent coverage across four operators [1](https://www.gsma.com/newsroom/press-release/sri-lankas-four-mobile-operators-commercially-launch-country-wide-network-apis-through-gsma-open-gateway-initiative-achieving-100-country-coverage/), banking via Sampath standardised API banking [2](https://www.ft.lk/financial-services/Sampath-Bank-pioneers-SL-s-standardised-API-banking-platform-redefining-transaction-banking/42-777823) [3](https://ceylontoday.lk/2025/06/19/sampath-bank-launches-sri-lankas-first-standardised-api-platform/), payments via LankaPay JustPay Web and PayHere, location via SLCities.live and location-api-sl, aviation via Aviation Edge CMB/VCBI, and niche APIs for holidays, NIC validation, postal codes, Sinhala Unicode, and cricket. The most production-ready Sri Lanka-specific surfaces are Hiru News https://hirunews.vercel.app/api [4](https://github.com/tharustack/Hiru-News-API), Esana https://esena-news-api-v3.vercel.app/ [5](https://github.com/ThaminduDisnaZ/Esena-News-API-Sinhala-News-API), SLCities.live https://slcities.live/api [6](https://github.com/dinethsiriwardana/Sri-Lanka-Location-Details), location-api-sl https://locatesrilanka.herokuapp.com/ [7](https://github.com/PasinduS96/location-api-sl), Sri Lanka Holidays https://srilanka-holidays.vercel.app/api/v1/ [8](https://github.com/Dilshan-H/srilanka-holidays), and CSE https://www.cse.lk/api/ [9](https://github.com/GH0STH4CKER/Colombo-Stock-Exchange-CSE-API-Documentation).

17. Implementation Playbook
News App: Hiru + Esana (no key, <5s) for Sinhala breaking + World News API source-country=lk for English multi-source + GNews fallback. Cache 60s, poll Esana 2-5 min.
Gov Dashboard: lanka_data HTTP for rapid demographic maps, CKAN package_search + datastore_search for tabular, World Bank for economic. For elections, scrape results.elections.gov.lk via lg_election_lk_2025 pattern.
Fintech: PayHere Checkout + Subscription Manager + Retrieval for cards/wallets; Sampath API Banking for corporate payouts; IdeaBiz Payment + GSMA Open Gateway for carrier billing across all telcos; JustPay Web via bank Open API (Seylan pattern) for bank-account direct debit; GovPay for government fee collection (3,372 services).
Logistics: SLCities.nearby + location-api-sl coordinates + Aviation Edge CMB timetable + MarineTraffic LKCMB AIS + ASYHUB manifest for customs.
Utilities: CEB SMS 1987 for outages, FuelPass.lk scrape for prices, GovPay for bill payment.
Calendar / Compliance: Sri Lanka Holidays API with X-API-Key for public/poya/bank holidays, NIC API for validation.

**Sri Lanka has a growing but fragmented ecosystem of public APIs and data sources.** Official government APIs are limited and mostly sector-specific or dataset-oriented (via portals and institutions), with no comprehensive central directory. Many details come from community-curated resources, open data initiatives, and institution sites. Full national-scale APIs (e.g., for citizen registries or all ministries) remain in development or pilot stages under frameworks like SNGAPI or Agriculture Interoperability efforts.



I conducted deep parallel research via targeted searches across official sites, GitHub directories, open data portals, news sources, financial institutions, mobile operators, and related sectors. This drew from multiple sub-agents equivalent to broad web investigations (government portals, data catalogs, sector-specific queries like health/weather/tourism/finance/news/sports/telecom, and niche explorations like legal/police/education). No single source covers "everything"—Sri Lanka's public data is often in JSON/PDF form or structured datasets rather than full REST APIs. Below is a compiled, exhaustive overview by sector, including direct links, endpoints where available, authentication notes, and coverage. Datasets (machine-readable JSON) are often more accessible than live APIs.



### 1. Government & Open Data Portals (Broad Coverage)

These provide the foundation for most Sri Lankan data via CKAN/ArcGIS-style interfaces. No single national API, but interconnected portals.

- **Sri Lanka Open Data Portal** (data.gov.lk): Official CKAN-based portal. Package list: https://data.gov.lk/api/3/action/package_list; full data JSON: https://data.gov.lk/data.json. Covers agriculture, demography, economy, transport, IT, cybersecurity. Datasets downloadable in JSON; API endpoints for querying packages. Free, public.

- **Ministry of Health Open Data Portal** (data.health.gov.lk): CKAN API: https://data.health.gov.lk/api/3 (package search/list available). Health statistics and digital health data. Free JSON access.

- **Department of Agriculture API** (api.doa.gov.lk/v1): Real-time/historical crop, agricultural statistics, weather data. Requires access_key (e.g., https://api.doa.gov.lk/v1/crops?access_key=YOUR_KEY). Free for basic use.

- **Lanka Data Foundation (LDF) Datasets** (ldflk.github.io/datasets): 212+ cleaned/structured JSON datasets (2019–2024/2025) from 15+ ministries/departments (e.g., SLTDA tourism stats/arrivals/accommodations/revenue; SL Bureau of Foreign Employment; Immigration/Emigration visas/asylum; Ministry of Foreign Affairs; Government Gazette). Interactive browser; bulk ZIP downloads. Not a live API but fully machine-readable for developers.

- **Survey Department Geoportals** (ArcGIS): Includes weather, marine environmental data. Endpoints via dateno.io or weather.meteo.gov.lk/server/rest/services. RESTful services for geospatial layers.

- **Other Government Gazette & Press Releases**: Documents.gov.lk for official notices; scraped datasets on GitHub (e.g., lk_datasets for Hansard, Supreme Court judgments, police press releases, Cabinet decisions). JSON/TXT/PDF mirrors; not official APIs but public data dumps.



**Upcoming/Planned**: Government API policies, SNGAPI (Secure National Government API) pilots for citizen/household data, Agriculture Interoperability Framework (data catalog for ministries).



### 2. Weather & Environment (Department of Meteorology)

- **Official Weather Portal & API**: https://weather.meteo.gov.lk (ArcGIS REST services). Observations, forecasts, alerts. Data JSON/PDF; some services exposed. Department of Meteorology site: meteo.gov.lk.

- **SL Cities API** (slcities.live/api): Geo data (cities, districts, provinces, postcodes, nearby). OpenAPI-documented endpoints. Free.



### 3. Tourism & Hospitality

- **SLTDA Data**: Monthly/annual arrivals, hotel occupancy, revenue reports (PDF/JSON via sltda.gov.lk). No dedicated public REST API; data structured for reuse.

- **LDF Tourism Datasets**: Arrivals/accommodations/revenue (cleaned JSON).



### 4. Financial & Economic Data

- **Colombo Stock Exchange (CSE)**: https://www.cse.lk/api/ (multiple POST endpoints, no key: companyInfoSummery, tradeSummary, todaySharePrice, topGainers, marketStatus, aspiData, chartData, etc.). Real-time/historical; unofficial but functional (reverse-engineered from portal).

- **Central Bank of Sri Lanka**: Statistics portal (cb.lk) for economic indicators, prosperity index, remittances. No public REST API; reports/data library.

- **Bank APIs (Corporate/Transaction)**: Individual banks have platforms (e.g., Sampath: developer.sampath.lk/devportal; DFCC iConnect; Nations Trust Open API). No central open banking yet (framework "upcoming"). Aggregators like BankSync cover many institutions for account info/payments (with consent).

- **Other**: LankaPay for payments; treasury press releases.



### 5. News & Media

- **Free/Live Aggregators**: GNews (gnews.io – country=lk), NewsData.io (country=lk), AP World News (source-country=lk), World News API (lk).

- **Sri Lanka-Specific Proxies/Scrapers**: Helakuru Esana (esena-news-api-v3.vercel.app), CeylonNewsBackend (GitHub scraper + API), RapidAPI "Latest Sri Lanka News" (scraped from major outlets; GraphQL/search features).

- **LDF/News Datasets**: Police press releases, Cabinet decisions, Treasury releases (JSON).



### 6. Telecommunications

- **GSMA Open Gateway**: Dialog, Airtel Lanka, Hutch, SLT-Mobitel. Commercial APIs: OTP validation, device location, carrier billing. Standard (CAMARA-based); country-wide.

- **Dialog Specific**: SMS/USSD/charging; AI assistant.



### 7. Sports (Cricket)

- **CricAPI / Sportradar / Others**: Sri Lanka coverage (fixtures, scores, stats). No official SLC standalone API; global providers include domestic/international matches (e.g., Lanka Premier League).

- **Cricsheet**: Ball-by-ball structured data (JSON) for international/SL matches (free download).



### 8. Education & Curriculum

- **BrainUs AI API**: Sri Lanka-specific (RAG on grades 1–13 curriculum with textbook citations). Public repo; SDKs for Python/JS. Query natural language for answers.

- **University Examples**: Some portals (e.g., University of Peradeniya) expose academic program/course APIs (semesters/courses).



### 9. Health & Other Sectors

- **COVID/Health**: HPB APIs (hpb.health.gov.lk – current stats, districts; public GET). Ministry Health portal.

- **Police**: eClearance system; press releases on GitHub. No public developer API.

- **Immigration/Foreign Affairs**: Datasets only (LDF); e-services on mfa.gov.lk/immigration.gov.lk.

- **Others**: No prominent public APIs found for judiciary, prisons, etc. (data often in e-services or PDFs).



### Additional Notes & Resources

- **Language/Tools**: Sinhala translation/dictionaries (Lingvanex, OpenSinhala); Unicode blocks.

- **Developer Communities**: GDG Sri Lanka, Sri Lanka Developer Forum, GitHub Sri Lanka for discussions.

- **Datasets vs. APIs**: Prioritize LDF/GitHub for machine-readable data; use open data portals for structured access. Many "APIs" are unofficial proxies or bank-specific.

- **Limitations**: No national citizen data API yet (pilots exist); some endpoints require keys or are sector-only. Open banking is nascent.



This covers the maximum researched (government, data portals, banks, mobile, sports, news, weather, tourism, health, education). For live testing, start with data.gov.lk or cse.lk/api. If you need details on a specific endpoint, sector, or integration example, provide more info!

- **Sri Lanka Open Data Portal (data.gov.lk)** — The official government open data initiative, with CKAN API endpoints like `data.gov.lk/api/3/action/package_list` and `data.gov.lk/data.json`, covering agriculture, demography, economy, transport, IT, and cybersecurity.
- **Ministry of Health Open Data (data.health.gov.lk)** — Health statistics via a CKAN API at `data.health.gov.lk/api/3`, including `package_search` and `package_list` actions.
- **Department of Agriculture API (api.doa.gov.lk)** — Real-time and historical agricultural data at base URL `api.doa.gov.lk/v1`, covering crop data, agri statistics, and weather, with an API key required.
- **Department of Census & Statistics (statistics.gov.lk)** — National statistical data including the Lanka Datta microdata catalog, the 2024 Census of Population and Housing, economic census data, and household surveys.
- **Coming soon:** New cross-government API guidelines are being developed, plus agriculture enterprise architecture APIs built through FAO collaboration.

## News & media

- **RSS feeds (the practical route)** — Most Sri Lankan outlets expose RSS rather than REST APIs: Ada Derana (adaderana.lk/rss.php), EconomyNext, News.lk, Newsfirst, Daily Mirror, The Island, Sunday Observer, Lankadeepa, Virakesari, Lanka Business Online, ITN News, and dozens more. Daily Mirror publishes its feeds at dailymirror.lk/rss.
- **NewsData.io** — Sri Lanka headlines via a country parameter, e.g. `newsdata.io/api/1/latest?country=lk&apikey=KEY`.
- **APITube News API** — Sri Lanka news search with historical data back to 1998, JSON/XML/CSV export, sentiment analysis and trend monitoring.
- From my own knowledge (verify current pricing/coverage): NewsAPI.org, GNews, Mediastack, Webz.io, and GDELT all support `country=lk`/Sri Lanka filters for aggregated local coverage.

## Telecom & network APIs

- **GSMA Open Gateway (all four operators)** — Bharti Airtel Lanka, Dialog Axiata, Hutchison, and SLT-Mobitel have commercially launched three network APIs — OTP Validation, Device Location, and Carrier Billing — giving developers one standard integration reaching over 21 million Sri Lankans across all networks, with local and global federation planned.
- **Ideamart / IdeaBiz (Dialog)** — Dialog's service delivery platform with SMS, USSD, and Charging-as-a-Service (CaaS) APIs, plus an AI assistant for developers.
- **SMS gateways** — Text.lk offers an SMS gateway REST API (with a PHP client), and WebSMS.lk is another open-source-friendly Sri Lankan SMS option. Notify.lk is another popular one from my knowledge.

## Finance, payments & markets

- **PayHere** — Sri Lanka's biggest online payment gateway, with documented APIs and SDKs plus e-commerce plugins, supporting Visa/Mastercard/Amex, wallets like Genie, Frimi, eZcash and mCash, and internet banking, in LKR/USD/EUR/GBP/AUD. Its Checkout API is a form-POST flow that redirects customers to PayHere and notifies your `notify_url` with a checksum-verified server callback.
- **Other gateways** — WebXPay (small-business-friendly IPG), Genie Business (Dialog-backed, strong QR payments), and DirectPay (modern APIs, low fees, fast settlement — considered one of the easiest to integrate for apps and enterprise software). OnePay and bank IPGs (Sampath PayCorp, Commercial Bank, etc.) also exist.
- **Colombo Stock Exchange (unofficial API)** — CSE's web portal exposes public endpoints at `cse.lk/api/` (POST requests) that are reverse-engineered and documented on GitHub, e.g. `companyInfoSummery` returning last traded price, change, and market cap per symbol. Known endpoints include marketSummery, aspiData (ASPI index), snpData (S&P SL20), chartData, allSectors, detailedTrades, dailyMarketSummery, topLooses, mostActiveTrades, and various announcement feeds. There's even a CSE MCP server (@gajarthan/cse-mcp) that wraps these into normalized tools for searching companies, quotes, market status, gainers/losers, and index data.
- **Licensed market data** — ICE distributes CSE equities data (Level 1 streaming and end-of-day) via its Consolidated Feed and APIs for enterprise integration.
- **Central Bank of Sri Lanka (CBSL)** — Publishes daily indicative exchange rates (LKR per world currency), USD/LKR spot rates, gold prices, and historical buying/selling rates from 2005 onward, plus an Economic Data Library with real, external, fiscal, and monetary sector indicators. No clean official REST API, but third parties like Fluentax expose CBSL rates via API (published ~09:30 Colombo time, Mon–Fri). World Bank, IMF, and ADB APIs also serve LK macro indicators.

## Transport

- **Sri Lanka Railways** — The official eservices.railway.gov.lk portal serves train schedules with times, stations, and ticket prices (scrapeable, no documented API). ICTA once provided a public JSON train-schedule API, but it's no longer publicly available and required contacting ICTA for access.
- **Community datasets** — Open projects maintain full timetable datasets (200+ routes with stops, classes, operating days) in JSON, and there are open-source bus route/shortest-path projects for Sri Lankan public transport. Also worth noting: a National Passenger Service Platform (multimodal transport) is being built under the Lanka Software Foundation's government projects.

## Holidays, calendar & culture

- **srilanka-holidays (Dilshan-H)** — An open-source API for official Sri Lankan holidays, live at srilanka-holidays.vercel.app, built with FastAPI, with data from 2021 onward in JSON, CSV, XML, and ICS formats, all manually validated from government sources.
- **Ministry of Technology official calendar** — An iCalendar/ICS holidays calendar based on the gazette by the Ministry of Home Affairs under the Holidays Act.
- **Commercial options** — HolidayAPI serves Sri Lankan public holidays, bank holidays, and observances ready for app integration; Calendarific and Nager.Date also cover LK.

## Location, identity & utility APIs

- **Provinces/Districts/Cities DB** — A full MySQL database of Sri Lankan provinces → districts → cities with postal codes, latitude/longitude, and trilingual names (Sinhala/Tamil/English), plus a hosted API providing postal codes, districts, and provinces.
- **Postal codes** — A community CSV of Sri Lankan postal codes (with some ~200 missing, mostly Northern Province), and curated lookup tools reconciled against Sri Lanka Post's official list.
- **NIC tools** — A Go-based API that generates and validates Sri Lankan NIC numbers (old and new formats), returning birth date, gender, serial, province, and even barcode content, plus Python decoders that extract birth date, gender, and NIC type from both formats with correct leap-year handling, and PHP NIC validators.
- **Language** — Lingvanex offers Sinhala translation and dictionary APIs (neural MT), and open-source tools include the OpenSinhala Dictionary, a 100k+ definition English–Sinhala database, Singlish converters, and subtitle translators.

## Datasets & development data

- Humanitarian Data Exchange hosts 133+ Sri Lanka datasets from 44+ organizations (crisis, disaster, population); World Bank and UNDP publish development indicators; and IOM's Displacement Tracking Matrix covers population mobility.

## Odds and ends worth knowing (from general knowledge — verify before relying)

The Department of Meteorology has no public API, so most builders use Open-Meteo or OpenWeatherMap with LK coordinates; disaster alerts come via the Disaster Management Centre site and ReliefWeb's API filtered to Sri Lanka. Cricket data for the national team is available through CricketData.org and similar cricket APIs. Exam results (doenets.lk), CEB power interruptions, and fuel prices have all had unofficial community scrapers/APIs at various points, but these tend to break — treat any GitHub project in those areas as needing a liveness check.

The biggest gaps you'll hit: CSE has no official public API despite its app offering real-time data, railways lost its public API, and most ministries publish PDFs rather than endpoints — so the unofficial/community layer is where much of the action is. Technical Directory and Sectoral Architecture Analysis of Sri Lankan Application Programming Interfaces and Open Data EcosystemsThe software ecosystem of Sri Lanka is undergoing a structural evolution, transitioning from siloed regional databases and ad-hoc scraping scripts to standardized RESTful interfaces, open government portals, unified telecommunications networks, and Model Context Protocol (MCP) implementations for autonomous artificial intelligence agents. Developers, system integrators, and enterprise architects operating within Sri Lanka navigate a multi-tiered data environment:Tier 1: Official Public and Open Government Infrastructures maintained by state departments, health ministries, and central banking institutions.Tier 2: Commercial Telecommunications and Financial Services governed by mobile network operators (MNOs) through unified Network-as-a-Service (NaaS) frameworks, alongside licensed payment service providers (PSPs) offering OAuth2-secured payment pipelines.Tier 3: Civic Technology Initiatives, Decoders, and Community Wrappers developed to bridge gaps in public data access, offering tools ranging from reverse-engineered capital market POST endpoints to National Identity Card (NIC) parsing engines and vernacular natural language processing tools.Public Sector, Open Government, and Civic InfrastructureState-sponsored digital transformation in Sri Lanka relies on centralized metadata repositories, departmental domain services, and civic software foundations.Centralized Open Data and Departmental PortalsThe primary node for public sector metadata discovery is the Sri Lanka Open Data Portal (data.gov.lk), built on the open-source Comprehensive Knowledge Archive Network (CKAN) platform. The portal exposes standardized CKAN Action API endpoints, allowing programmatic querying of datasets, package listings, and resource metadata:Package List Endpoint: https://data.gov.lk/api/3/action/package_list[cite: 1]Data Catalog Schema: https://data.gov.lk/data.json[cite: 1]The catalog spans critical socio-economic domains, including agricultural yields, transport logistics, regional demographic shifts, macroeconomic indicators, information technology adoption, and cybersecurity posture.A parallel implementation exists in the healthcare domain via the Ministry of Health Open Data Portal. Executive Summary
Sri Lanka’s API ecosystem spans government portals, news/media feeds, finance gateways, transport and utility data, etc. Key government APIs include the Sri Lanka Open Data Portal (data.gov.lk) and the Ministry of Health Open Data Portal (data.health.gov.lk), both CKAN-based and publicly accessible. For example, data.gov.lk exposes CKAN endpoints (/api/3/action/package_list, /data.json), while data.health.gov.lk similarly provides CKAN APIs (/api/3, /action/package_search). The Department of Agriculture also runs an API (api.doa.gov.lk) for crop and weather data (key-protected). Many national news outlets lack dedicated APIs but offer RSS feeds: e.g. the Daily Mirror and Daily FT maintain multiple RSS channels for breaking news, sectors and features. News aggregator services (NewsData.io, APITube) also support Sri Lanka news via RESTful endpoints.

In finance, Sri Lankan payment gateways provide modern APIs. PayHere (a leading gateway) offers a web “Checkout API” (POST with HMAC) requiring a merchant ID/secret and SHA-256 signature. It returns JSON responses and provides official SDKs (JavaScript, Android, iOS, React Native, Flutter). PayHere is PCI-DSS and ISO27001 certified, advertises no setup or hidden fees, and offers usage-based pricing (no monthly fee on basic plans). OnePay is another Sri Lankan gateway with a REST API (authenticated via an App ID and hash salt) that uses JSON and enforces rate-limiting (429 on excess). Stock market data comes via the Colombo Stock Exchange: CSE partners with ICE, offering real-time and historical data through the ICE Data API and feeds (licensed, high-uptime). Central Bank data (e.g. exchange rates) must be scraped or obtained via third parties: for instance, AllRatesToday provides a JSON API mirror of CBSL rates and Fluentax offers an API for Sri Lanka rates as part of its service.

In other sectors, many APIs are limited or absent. Transport: Sri Lanka Railways has schedules only on its website (no open API) and the bus system (SLTB) has no public API. Health: aside from the Health Data Portal, private services (e.g. eChannelling for doctor appointments) have no public APIs. Utilities: the Ceylon Electricity Board shows real-time generation on its site (e.g. daily net energy statistics) but provides no developer API. Tourism/Maps: use of global services (Google Maps, OpenWeather) covers Sri Lanka but no specialized local APIs were found. Legal: the Parliament of Sri Lanka has no documented API, though an unofficial API was reverse‑engineered from its mobile app; endpoints like /news, /acts, /member_list exist (POST calls).

Overall, our survey identified on the order of a few dozen relevant APIs. Most major government and telecom entities are moving towards open data and APIs, but many legacy sites still rely on RSS feeds or screen scraping. The tables below summarize the key APIs by sector. # Mapping the Open and Hidden API Landscape of Sri Lanka: A Comprehensive Discovery Report

## Officially Documented Government and State-Owned Enterprise APIs

The landscape of publicly documented Application Programming Interfaces (APIs) within Sri Lanka's government and state-owned enterprises (SOEs) reveals a nascent but strategically evolving ecosystem. This infrastructure is characterized by a dual approach: on one hand, a move towards centralized, standardized data access through dedicated developer portals; on the other, the continued provision of valuable datasets through more traditional, often geospatial, web services. These APIs represent the formal channels through which developers, researchers, and private sector entities can access a wide array of public data, ranging from national economic indicators and transportation networks to administrative boundaries and news content. The emergence of platforms like the Sri Lanka Digital Payment Infrastructure (SLUDI) Developer Portal signals a concerted effort by the government to modernize its digital services and foster a culture of data transparency [[188](https://docs.dev.digieconcenter.gov.lk/docs/changelog), [189](https://docs.dev.digieconcenter.gov.lk/)]. This initiative is complemented by numerous tenders and project documents from various ministries, which explicitly mandate adherence to API standards, including the provision of Swagger documentation, indicating a growing institutional awareness of the importance of well-documented interfaces [[174](https://slaasmb.gov.lk/wp-content/uploads/2021/03/TOR-MIS-development-SLAASMB.pdf), [175](https://slaasmb.gov.lk/wp-content/uploads/2021/05/request_for_proposal_rfp_mis_development_of_slaasmb.pdf), [176](https://measurementsdept.gov.lk/images/BIDDING_DOCUMENT_FOR_Measurement_Standards_Management_Information_System_MSMIS/Bidding_Document_Volume_02.pdf), [178](https://www.colombo.mc.gov.lk/postimages/files/CPD%2018-%20360-2022%20Docu%20DULICATE%20(1).pdf)].

A cornerstone of this emerging ecosystem is the Sri Lanka DPI Developer Portal, which serves as an official hub for accessing government services [[190](https://docs.dev.digieconcenter.gov.lk/docs/getting-started/gateway-errors), [191](https://developerportal.dev.digieconcenter.gov.lk/)]. This portal provides developers with interactive documentation rendered in formats like ReDoc and Swagger UI, allowing for direct exploration and testing of APIs without needing to write code first [[188](https://docs.dev.digieconcenter.gov.lk/docs/changelog)]. Access to the portal is streamlined through single sign-on options like Google and GitHub accounts, lowering the barrier to entry for developers [[191](https://developerportal.dev.digieconcenter.gov.lk/)]. The portal's existence and its active development, as evidenced by a changelog detailing updates, suggest it is a living platform intended to manage subscriptions, handle gateway errors, and facilitate secure application connectivity [[188](https://docs.dev.digieconcenter.gov.lk/docs/changelog), [189](https://docs.dev.digieconcenter.gov.lk/), [190](https://docs.dev.digieconcenter.gov.lk/docs/getting-started/gateway-errors)]. Within this portal, specific functionalities are exposed, such as the integration with Verifiable Credentials through a defined template layout and attribute mapping process [[192](https://docs.dev.digieconcenter.gov.lk/docs/guide/guide-sludi-integration)]. This indicates that the government is not only providing raw data but also enabling advanced digital identity solutions. The portal's focus on workflow profiling and groupings further points to its use in managing complex, multi-step government processes [[178](https://www.colombo.mc.gov.lk/postimages/files/CPD%2018-%20360-2022%20Docu%20DULICATE%20(1).pdf)]. While the full scope of APIs available through SLUDI/DPI is extensive, its very existence marks a significant step towards creating a unified, governed point of access to government data, moving away from fragmented, siloed systems.

Beyond centralized portals, several key government departments and SOEs have made significant datasets available through documented APIs. The Ministry of Transport and Highways stands out for its comprehensive provision of geographic information system (GIS) data. The ministry offers a suite of transport-related layers through ArcGIS REST Services, covering air, land, and sea transportation infrastructure [[23](https://gisapps.nsdi.gov.lk/server/rest/services/Srilanka/Transport/MapServer/layers), [25](https://gisapps.nsdi.gov.lk/server/rest/services/Srilanka/Transport/MapServer)]. These layers include detailed information on helicopter pads, airports, railway infrastructure, expressways, main roads, and secondary roads [[23](https://gisapps.nsdi.gov.lk/server/rest/services/Srilanka/Transport/MapServer/layers), [27](https://gisapps.nsdi.gov.lk/server/rest/services/Srilanka/Transport/MapServer/legend)]. Developers can access these layers via a JSON-based API reference, allowing them to build applications that require foundational geographic context for logistics, urban planning, and navigation [[26](https://gisapps.nsdi.gov.lk/server/rest/services/Srilanka/Transport/MapServer/layers?dynamicLayers=%5B%5D&)]. The availability of OGC-compliant services like WFS (Web Feature Service) further enhances interoperability, enabling users to integrate this data into a variety of GIS software [[125](https://www.arcgis.com/sharing/rest/content/items/e143f436d4774402aa8cca1e663b1d24/info/metadata/metadata.xml), [126](https://www.arcgis.com/sharing/rest/content/items/54f40ddee0844fb285dafb13a6b2f623/info/metadata/metadata.xml?format=fgdc), [127](https://www.arcgis.com/sharing/rest/content/items/5bc82e3026354c9d92cbb551b3b2e2d2/info/metadata/metadata.xml), [128](https://www.arcgis.com/sharing/rest/content/items/db8bdecc473646cd859c625508334483/info/metadata/metadata.xml?format=fgdc)]. Similarly, the Department of Irrigation has provided public, keyless access to its river-gauge monitoring systems via ArcGIS feature services [[36](https://github.com/shakee93/sl-water-levels)]. This allows for the real-time retrieval of station locations and water level readings, a critical dataset for flood prediction and agricultural planning. The impact of this open data is amplified by community-driven innovations, such as a Next.js dashboard that visualizes the real-time water levels and even exposes the underlying data as a Multi-Command Protocol (MCP) server for integration with AI tools like Claude Code, demonstrating the potential for creative reuse of government-provided data [[36](https://github.com/shakee93/sl-water-levels)].

The Central Bank of Sri Lanka (CBSL) is another pivotal institution contributing to the public data ecosystem. It operates a library where users can search thousands of data items and generate reports on a vast range of economic indicators [[77](https://www.cbsl.gov.lk/en/statistics/data)]. Furthermore, the CBSL has made its annual "Sri Lanka Socio-Economic Data-2025" publication publicly available, offering a comprehensive snapshot of the nation's economic and social landscape [[167](https://www.facebook.com/newswireLK/posts/the-central-bank-of-sri-lanka-has-made-available-to-the-public-the-sri-lanka-soc/1361775759292144/)]. While these resources may not always be delivered via a real-time RESTful API, they form a crucial part of the economic data foundation. The bank's strategic direction towards developing an Open API Framework underscores its commitment to fostering a more dynamic financial data environment [[197](https://www.cbsl.gov.lk/sites/default/files/cbslweb_documents/about/central_banks_policy_agenda_for_2026_and_beyond_e.pdf)]. This aligns with broader government policy goals, such as the Draft National Policy on Transport, which emphasizes boosting efficiency in the logistics industry [[116](https://npd.treasury.gov.lk/files/PIP%202026-2030%20final_new.pdf)], and the Urban Transport System Development Project, which relies on sophisticated transport planning models [[109](https://www.transport.gov.lk/web/images/downloads/F-CoMTrans_Main_S.pdf)]. The involvement of major SOEs in these initiatives highlights their central role. For instance, the Sri Lanka Ports Authority (SLPA), a key SOE, reported achieving a record high throughput of 2.41 million TEUs in 2024, showcasing its critical role in international trade [[5](https://www.facebook.com/adaderana/posts/sri-lanka-ports-authority-achieves-record-high-throughput/916927220604640/)]. Another major SOE, Sri Lanka Railways (SLR), functions as a government department under the Ministry of Transport and is actively involved in multimodal logistics solutions, including launching new intercity train services and promoting road-to-rail freight movement [[4](https://www.railway.gov.lk/web/index.php?option=com_content&view=article&id=1), [7](https://www.unescap.org/sites/default/d8files/event-documents/May18_Draft-report-for-Sri-Lanka.pdf), [9](https://www.instagram.com/p/DSkLvt8jZuC/?hl=en)]. Although direct, comprehensive operational APIs for SLPA or SLR were not identified in the provided sources, their mention as potential shareholders in transport projects suggests future opportunities for data sharing [[6](https://www.adb.org/sites/default/files/project-documents/41249-022-tacr-01.pdf)].

## Financial Sector APIs: Stock Exchanges, Banks, and Economic Data

The financial sector in Sri Lanka presents a distinct duality in its API landscape: a highly regulated, formally mandated internal system for trading participants coexisting with a vibrant community of developers who have reverse-engineered public-facing endpoints to extract valuable market data. At the heart of this ecosystem is the Colombo Stock Exchange (CSE), which requires all trading participants to utilize a specific Gateway and Application Program Interface (API) for submitting trading orders [[19](https://cdn.cse.lk/pdf/rss/Trading+Rules+pertaining+to+RSS-Approved+by+SEC.pdf), [20](https://cdn.cse.lk/pdf/new-trading-rules/SECTION-5.pdf), [22](https://cdn.cse.lk/pdf/rule-books/jBZAYMJkwM6IIHFy_27Jan2025130153GMT_1737982913753.pdf)]. This CSE-mandated API is not a public resource; it is a proprietary, controlled interface designed for institutional clients, ensuring a standardized and secure method for executing trades. The rules stipulate that trading participants must comply with any enhancements to these Gateway/API specifications published by the CSE, highlighting the authority's control over the technical architecture of its trading floor [[20](https://cdn.cse.lk/pdf/new-trading-rules/SECTION-5.pdf), [22](https://cdn.cse.lk/pdf/rule-books/jBZAYMJkwM6IIHFy_27Jan2025130153GMT_1737982913753.pdf)]. Beyond this core function, the CSE offers data products for purchase, such as Real-Time Equity Market Data, priced at $22,000, indicating a commercial model for high-value, near-real-time data feeds for professional users [[21](https://cdn.cse.lk/pdf/CSEDATAPRODUCTSPRICELIST.pdf)].

Despite the closed nature of the primary trading API, a significant discovery by the developer community has revealed a set of publicly accessible, undocumented endpoints that mirror the functionality of the CSE's official website [[63](https://github.com/heyisula/cse-unofficial-api-data-pipeline)]. This research uncovered a stable set of POST-based API endpoints hosted at `https://www.cse.lk/api/`. These endpoints provide a wealth of market intelligence that is invaluable for retail investors, analysts, and developers building third-party financial applications. Key accessible endpoints include `marketStatus`, `marketSummery`, `todaySharePrice`, `companyInfoSummery` (which requires a stock symbol parameter), `tradeSummary`, `topGainers`, `topLooses`, `aspiData`, `snpData`, and `allSectors` [[63](https://github.com/heyisula/cse-unofficial-api-data-pipeline)]. The successful extraction of this data demonstrates that even without an official public API, valuable information streams can be accessed by understanding the client-side requests made by the official web portal. This finding is critical as it democratizes access to certain types of market data that were previously difficult to obtain programmatically.

However, the analysis of these reverse-engineered endpoints also reveals important limitations and nuances. Accessing these public endpoints is not straightforward; it requires mimicking the behavior of a legitimate browser session. Specifically, requests must include a valid session cookie (`JSESSIONID`) and specific headers such as `Origin`, `Referer`, and `X-Requested-With` [[63](https://github.com/heyisula/cse-unofficial-api-data-pipeline)]. This indicates a defense-in-depth strategy by the CSE to deter simple, automated scraping while still allowing the official website to function correctly. Furthermore, the investigation found that some data is intentionally gated and cannot be easily accessed. Endpoints like `chartData` require hidden parameters, `companyChartDataByStock` depends on an unstable `stockId`, and `detailedTrades` is protected by session guards and rate limits [[63](https://github.com/heyisula/cse-unofficial-api-data-pipeline)]. This distinction between accessible summary data and restricted, granular data is a crucial insight into the CSE's data-sharing philosophy. A Python script developed by the community automates the collection of data from the accessible endpoints every 60 seconds during market hours, storing it in timestamped JSON files and providing a zero-fill fallback mechanism to ensure data consistency [[63](https://github.com/heyisula/cse-unofficial-api-data-pipeline)]. This project serves as both a proof-of-concept and a ready-made tool for anyone wishing to monitor Sri Lanka's stock market activity.

The Central Bank of Sri Lanka (CBSL) is another key player whose API strategy is shifting towards greater openness. While historically focused on publishing reports and data libraries [[77](https://www.cbsl.gov.lk/en/statistics/data), [167](https://www.facebook.com/newswireLK/posts/the-central-bank-of-sri-lanka-has-made-available-to-the-public-the-sri-lanka-soc/1361775759292144/)], the CBSL is now actively working on establishing an Open API Framework [[197](https://www.cbsl.gov.lk/sites/default/files/cbslweb_documents/about/central_banks_policy_agenda_for_2026_and_beyond_e.pdf)]. This framework is envisioned as a means to enable secure, standardized data exchange with external stakeholders, a move that aligns with global trends in financial technology [[197](https://www.cbsl.gov.lk/sites/default/files/cbslweb_documents/about/central_banks_policy_agenda_for_2026_and_beyond_e.pdf)]. The bank has already initiated consultations on Open Banking and API-related initiatives, signaling a clear strategic intent to foster a more interconnected financial ecosystem [[144](https://www.cbsl.gov.lk/sites/default/files/cbslweb_documents/about/forms_20204004_psd_new_guidelines_for_public_consultation_e.docx)]. This development is expected to unlock a new wave of innovation in areas like personal finance management, credit scoring, and fintech services. In the interim, developers seeking macroeconomic data can turn to external platforms like FRED (Federal Reserve Economic Data) from the St. Louis Fed, which hosts a substantial number of series tagged with "Sri Lanka" and "Banks," covering metrics like bank assets to GDP [[34](https://fred.stlouisfed.org/tags/series?t=banks%3Bsri+lanka), [75](https://fred.stlouisfed.org/tags/series?t=sri+lanka)]. The World Bank also offers an API for retrieving its public documents, which could include reports relevant to Sri Lanka's economic situation [[76](https://documents.worldbank.org/en/publication/documents-reports/api), [78](https://api.worldbank.org/v2/source/75/indicators)].

However, reliance on such endpoints carries inherent risks, as they are not guaranteed to remain stable or accessible indefinitely. The future of the financial API ecosystem in Sri Lanka will likely be shaped by the implementation of the CBSL's Open API Framework, which promises to create a standardized, reliable, and officially sanctioned channel for accessing financial data, thereby encouraging more robust and sustainable application development. Until then, the ingenuity of the developer community remains the primary engine driving access to Sri Lanka's financial data.

## Telecommunications and SMS Gateway APIs

The telecommunications sector in Sri Lanka has emerged as a powerful and dynamic source of APIs, driven largely by the strategic initiatives of major mobile network operators (MNOs). These APIs extend far beyond simple connectivity, offering developers programmatic access to carrier infrastructure, location-based services, and messaging capabilities tailored for the Sri Lankan market. This domain represents a fertile ground for innovation in areas such as mobile commerce, location-based marketing, and secure user verification. The most prominent platform in this space is Dialog Axiata PLC's Ideamart, which has evolved from a simple marketplace for mobile content into a globally recognized developer ecosystem [[119](http://island.lk/dialog-axiatas-ideamart-partners-with-hutch-to-expand-app-developers/), [165](https://ideamart.lk/)]. Ideamart provides a suite of APIs that allow developers to expose MNO infrastructure to a wide audience, enabling the creation of innovative digital solutions [[155](https://www.dailymirror.lk/print/ict/Hutch-expands-Ideamart-subscriber-reach/269-114105), [165](https://ideamart.lk/)]. The platform has undergone a significant evolution, transitioning from the older Ideamart system—which used App ID and password authentication within a JSON body—to Ideabiz, which leverages a more modern and secure OAuth2 protocol for authentication [[166](https://docs.ideabiz.lk/Tips/IdeamarttoIdeaBiz/)]. This progression reflects a maturation of the platform and a commitment to adhering to contemporary API security best practices.

Ideamart/Ideabiz is not just a theoretical concept; it has tangible business applications. For example, Hutchison Telecom has partnered with Ideamart to expand its subscriber reach and offer new services, demonstrating how incumbent telcos leverage these platforms to enhance their offerings [[118](https://hutch.lk/dialog-axiatas-ideamart-partners-with-hutch-to-expand-subscriber-reach/), [119](http://island.lk/dialog-axiatas-ideamart-partners-with-hutch-to-expand-app-developers/)]. The platform's ability to integrate with other service providers highlights its role as a central nervous system for mobile services in Sri Lanka. Developers can use these APIs to build services that are deeply integrated with the local mobile landscape, such as carrier billing, device location tracking, and identity verification based on the user's carrier [[65](https://dialog.lk/news/sri-lankas-four-mobile-operators-commercially-launch-country-wide-network-apis)]. The strategic importance of this infrastructure is underscored by SLT-Mobitel's own decision to launch three value-creating APIs focused on One Time Password (OTP) validation, device location, and carrier billing, indicating that this capability is becoming a standard feature offered by all major MNOs in the country [[65](https://dialog.lk/news/sri-lankas-four-mobile-operators-commercially-launch-country-wide-network-apis)].

Complementing the offerings of the major telcos are a number of specialized SMS gateway providers that cater to businesses requiring bulk messaging, promotional campaigns, and transactional notifications. These providers offer well-documented APIs that support standard authentication methods like Bearer tokens. Text.lk, positioned as Sri Lanka's #1 AI-powered SMS gateway, provides a comprehensive API for sending bulk, promotional, transactional, and OTP messages, along with features like MMS and WhatsApp integration [[66](https://text.lk/docs/api-endpoints-introduction/), [132](https://text.lk/)]. Their documentation specifies the use of an API key sent in the `Authorization: Bearer [access_token]` header for authentication, a common practice in modern RESTful APIs [[207](https://text.lk/docs/textlk-ios-swift-integration/)]. Other notable local providers include Richmo, which offers a developer guide with examples in PHP and Python, and SMSAPI.LK, which also utilizes a custom Base URL for its API endpoint, allowing for flexibility in integration [[67](https://www.richmo.lk/api-guide), [68](https://smsapi.lk/), [70](https://github.com/sdglhm/dialog_lk_esms)]. Mobile Solutions (Pvt) Ltd, the provider of the Mobitel-SMS (MSMS) Library for Laravel, offers a secure method for organizations to send and receive bulk SMS messages [[206](https://github.com/joeljerushan/Mobitel-SMS)]. Clickatell and Telnyx provide global SMS API platforms that cover Sri Lanka, offering robust two-way messaging capabilities and detailed compliance guidelines for sending messages to the country [[61](https://www.clickatell.com/enterprise-solutions/sms-api/), [153](https://support.telnyx.com/en/articles/6680171-sri-lanka-sms-guidelines)]. Clickatell's documentation shows an API endpoint for sending SMS that uses an access token in the header, again confirming the prevalence of Bearer token authentication [[203](https://www.scribd.com/document/662529248/API-Documentation-for-hutch-sri-lanka)]. The existence of these diverse providers gives businesses in Sri Lanka a choice of platforms, each with its own pricing, features, and technical requirements.

## News, Media, and Information APIs

The landscape of news and media APIs relevant to Sri Lanka is diverse, encompassing large-scale global aggregators, niche community-built solutions for local languages, and the official communications channels of the government. This multi-layered ecosystem provides developers with numerous pathways to access information, from breaking news headlines to historical archives and government announcements. For applications requiring broad, reliable, and well-structured news data, global news aggregators present the most straightforward solution. Services like NewsData.io and NewsAPI.ai stand out for their extensive coverage, sourcing content from hundreds of thousands of outlets worldwide, including numerous Sri Lankan news websites [[41](https://newsdata.io/), [42](https://newsapi.ai/)]. NewsData.io, for instance, claims to provide access to over 102,000 sources and offers a decade of historical news data dating back to January 2016, alongside real-time feeds [[41](https://newsdata.io/), [46](https://newsdata.io/news-sources/sri-lanka-news-api)]. These platforms typically offer robust, easy-to-integrate APIs with features like keyword search, feed access, and large daily request allowances, making them ideal for developers building news readers, sentiment analysis tools, or content aggregation platforms [[42](https://newsapi.ai/), [79](https://currentsapi.services/en)]. Their strength lies in their scale, reliability, and the richness of their metadata, though they may not always provide the deepest level of granularity into hyper-local Sri Lankan stories compared to native sources.

At the other end of the spectrum are the community-curated and unofficial APIs that serve a critical role in providing access to local, often Sinhala-language, news content. A prime example is the API for Hiru News, a popular Sinhala news outlet [[45](https://github.com/tharustack/Hiru-News-API)]. This production-ready REST API provides real-time news articles with full-text extraction, images, and categorization, filling a vital gap for developers who need to work with Sinhala-language data programmatically. Similarly, an unofficial API for Helakuru Esana, described as Sri Lanka's leading news provider, acts as a proxy to fetch live data from the outlet's own JSON endpoint [[54](https://github.com/ThaminduDisnaZ/Esena-News-Github-Bot)]. This API returns a structured JSON object containing article titles in both Sinhala and English, full content, timestamps, and engagement metrics like likes and comments [[54](https://github.com/ThaminduDisnaZ/Esena-News-Github-Bot)]. These community-built solutions are invaluable because they are often faster to develop and adapt to changes on local websites than waiting for official, formal APIs. They are typically maintained by passionate individuals or small groups who recognize a need within the local developer community. The `Awesome-Sri-Lanka` GitHub repository serves as a curated directory that helps surface these kinds of resources, acting as a de facto index of public APIs and datasets relevant to the country [[44](https://github.com/kaveenexe/Awesome-Sri-Lanka), [80](https://github.com/nicolasize/Awesome-Sri-Lanka), [81](https://github.com/nicolasize/Awesome-Sri-Lanka/releases)].

For official and authoritative news, the primary sources are the government's own platforms. News.lk is presented as the official government news portal, providing timely updates and comprehensive coverage in Sinhala, Tamil, and English [[48](https://www.news.lk/), [199](https://tamil.news.lk/)]. Lankapuvath, the national news agency of Sri Lanka, is another key entity, with a significant social media presence indicating its role as a primary source of state-aligned news [[47](https://en.wikipedia.org/wiki/Lankapuvath), [160](https://www.facebook.com/LankapuvathOfficialPage/about/)]. While these platforms are the ultimate sources of truth for government announcements and official statements, the provided documentation does not confirm the existence of a formal, machine-readable API for their content. Access to their information is therefore likely limited to web scraping or manual consumption. The Sri Lanka Tourism Development Authority (SLTDA) also maintains a web service for providing information on registered tourism service providers, although the specifics of this web service are not detailed in the sources [[52](https://www.sltda.gov.lk/storage/common_media/Web%20Supporting%20Services%20Doc%20Final689185666.pdf)]. This suggests that while individual government bodies may have internal APIs for partner integrations, a centralized, public-facing news API for the entire country does not appear to exist.

## Reverse-Engineered and Unofficial APIs: The Hidden Data Layer

The most profound and novel discoveries within the Sri Lankan API landscape come from the realm of reverse-engineered and unofficial endpoints. These APIs were not created or published by their respective owners but were uncovered by determined developers and security researchers investigating the digital footprints of various organizations. This "hidden layer" of data access directly addresses the user's goal of finding resources that are "where no one would have tried or got ever." The methodologies employed range from analyzing mobile app traffic with tools like Charles Proxy to writing scripts that mimic the behavior of official websites, revealing a treasure trove of unsecured or poorly secured data streams [[91](https://www.davidxia.com/2020/10/how-to-analyze-mobile-app-traffic-and-reverse-engineer-its-non-public-api/), [93](https://medium.com/@rehmat_87380/reverse-engineering-mobile-apps-to-open-new-doors-of-data-9d8f7e01ac53)]. These findings are not merely academic exercises; they demonstrate the existence of valuable, often real-time, data that is technically accessible but not officially supported, creating a unique category of risk and opportunity for developers.

One of the most significant discoveries is the reverse-engineering of the Colombo Stock Exchange (CSE) website to expose its public-facing data endpoints [[63](https://github.com/heyisula/cse-unofficial-api-data-pipeline)]. As previously discussed, this effort revealed a set of stable, POST-based API calls that power the CSE's public web portal. The research went further, documenting the precise headers (`Origin`, `Referer`, `X-Requested-With`) and the necessity of a session cookie (`JSESSIONID`) to make these calls successfully [[63](https://github.com/heyisula/cse-unofficial-api-data-pipeline)]. This level of detail demystifies the process and empowers others to replicate the data collection. The discovery effectively creates a free, unofficial API for market data, complete with a working Python script that automates the process of polling the endpoints every minute during market hours [[63](https://github.com/heyisula/cse-unofficial-api-data-pipeline)]. This project is a masterclass in how to extract value from a system not designed for programmatic access. It uncovers a clear distinction between what is possible to scrape easily (market summaries, top performers) and what is deliberately gated (detailed trade logs, intraday charts), providing a nuanced map of the exchange's data accessibility.

Another critical find is the uncovering of an unsecured internal API belonging to the Sri Lankan Ministry of Health (MOH) [[53](https://github.com/sudeepaviraj/administrative-api-srilanka/blob/main/DataScrape.py)]. A Python script was discovered that scrapes administrative division data (provinces, districts, divisional secretariats) from the MOH's `apps.moha.gov.lk` website. The script identifies two key endpoints: an initial GET request to `http://apps.moha.gov.lk:8090/lifecode/village_list` to fetch province data, followed by a POST request to `http://apps.moha.gov.lk:8090/lifecode/views/fetch.php` to retrieve subsequent levels of administrative units [[53](https://github.com/sudeepaviraj/administrative-api-srilanka/blob/main/DataScrape.py)]. The significance of this discovery lies in the security posture of the API itself. The use of a non-standard port (`:8090`) and the lack of HTTPS encryption (with SSL verification disabled in the script) strongly suggest that this endpoint was never intended for public consumption and is running in a poorly secured environment [[53](https://github.com/sudeepaviraj/administrative-api-srilanka/blob/main/DataScrape.py)]. This represents a classic example of an internal or semi-public system being left exposed to the internet, offering a rare glimpse into a government's administrative structure. The data provided—a hierarchical list of geographic and administrative divisions—is foundational for countless applications in logistics, public service delivery, and demographic analysis.

The world of lotteries in Sri Lanka also lacks formal APIs, but this gap has been filled by a community-driven solution. The `srilanka-lottery` Python package is a scraper designed specifically to extract results from the websites of both the National Lottery Board (NLB) and the Development Lottery Board (DLB) [[55](https://github.com/Ishanoshada/Srilanka-Lottery/releases)]. This package provides clean, high-level functions for fetching the latest results, listing active lottery names, or checking a specific draw result. It supports a wide range of games from both boards, including Mega Power, Dhana Nidhanaya, Ada Kotipathi, and Sasiri [[55](https://github.com/Ishanoshada/Srilanka-Lottery/releases)]. This project exemplifies grassroots innovation, solving a specific problem for a niche audience with a well-structured, reusable piece of software. It proves that even for seemingly trivial data, if there is a demand, a developer community will arise to meet it, effectively creating an ad-hoc API through web scraping.

Perhaps the most cautionary tale from this category of discovery is the case of Sri Lanka's 'StaySafe' COVID-19 tracker [[64](https://ruky.me/using-your-browsers-developer-tools-to-finding-vulnerabilities/)]. Researchers reverse-engineered the platform's backend and uncovered severe security vulnerabilities. Most alarmingly, they found that an individual's COVID-19 infection status could be checked simply by sending their National Identity Card (NIC) number in a GET request to an unauthenticated endpoint [[64](https://ruky.me/using-your-browsers-developer-tools-to-finding-vulnerabilities/)]. Furthermore, the admin dashboard for merchants was accessible without any authentication, and a front-end JavaScript check for a valid merchant ID could be bypassed by manually editing the browser's local storage. Logging into this compromised admin panel allowed the researchers to pull down a complete dump of all over 8,000 registered user records, including their NIC numbers, mobile numbers, and infection status [[64](https://ruky.me/using-your-browsers-developer-tools-to-finding-vulnerabilities/)]. This case study is a stark reminder of the risks associated with poor API design and inadequate security controls. The fact that the vulnerabilities were patched quickly after disclosure is a testament to responsible disclosure practices, but it also highlights the fragility of public-facing health systems [[64](https://ruky.me/using-your-browsers-developer-tools-to-finding-vulnerabilities/)]. These reverse-engineered findings collectively paint a picture of a digital ecosystem where valuable data exists in unexpected places, often guarded by weak or nonexistent security measures, presenting both immense opportunities for discovery and significant ethical responsibilities for those who find it.

## Synthesis of the Sri Lankan API Ecosystem and Strategic Implications

The comprehensive discovery of APIs related to Sri Lanka reveals a dynamic, fragmented, and rapidly evolving digital infrastructure. The landscape is not defined by a single, monolithic platform but rather by a mosaic of official portals, corporate gateways, community-driven projects, and hidden, reverse-engineered endpoints. This synthesis of findings illuminates several overarching themes and provides a strategic roadmap for any entity seeking to leverage Sri Lanka's digital data. The most salient characteristic of this ecosystem is its inherent duality: a tension between official, progressive moves towards data openness and the reality of insecure, undocumented systems that persist within the country's public and private sectors. On one side, the establishment of the Sri Lanka DPI Developer Portal [[188](https://docs.dev.digieconcenter.gov.lk/docs/changelog), [189](https://docs.dev.digieconcenter.gov.lk/)] and the Central Bank's push for an Open API Framework [[197](https://www.cbsl.gov.lk/sites/default/files/cbslweb_documents/about/central_banks_policy_agenda_for_2026_and_beyond_e.pdf)] signal a clear and deliberate strategy by the government and key regulatory bodies to foster a transparent, data-driven economy. These initiatives are backed by procurement policies that mandate modern API standards like Swagger, indicating a systemic shift towards better-architected and more maintainable systems [[174](https://slaasmb.gov.lk/wp-content/uploads/2021/03/TOR-MIS-development-SLAASMB.pdf), [176](https://measurementsdept.gov.lk/images/BIDDING_DOCUMENT_FOR_Measurement_Standards_Management_Information_System_MSMIS/Bidding_Document_Volume_02.pdf)]. Concurrently, the provision of raw, keyless GIS data from the Ministry of Transport [[23](https://gisapps.nsdi.gov.lk/server/rest/services/Srilanka/Transport/MapServer/layers)] and the Department of Irrigation [[36](https://github.com/shakee93/sl-water-levels)] demonstrates a commitment to making foundational data freely available to fuel innovation.

However, this narrative of progress is counterbalanced by the frequent discovery of poorly secured internal systems. The unsecured API within the Ministry of Health [[53](https://github.com/sudeepaviraj/administrative-api-srilanka/blob/main/DataScrape.py)] and the critically flawed authentication on the StaySafe COVID-19 tracker [[64](https://ruky.me/using-your-browsers-developer-tools-to-finding-vulnerabilities/)] are not isolated incidents but symptomatic of a broader pattern. These vulnerabilities suggest that many organizations, regardless of their public or private status, have not fully embraced modern cybersecurity principles. This creates a "hidden API economy"—a layer of data that is ripe for discovery but fraught with risk. For a developer or researcher, this duality is both a challenge and an opportunity. It necessitates a multi-layered discovery strategy that begins with official channels but extends to the investigative work of reverse engineering and community curation.

The second major theme is the undeniable power of the developer community as an agent of discovery. When official APIs are absent or insufficient, communities fill the void. The `Awesome-Sri-Lanka` repositories on GitHub serve as a crucial, decentralized index of local resources, highlighting the importance of peer-to-peer knowledge sharing [[44](https://github.com/kaveenexe/Awesome-Sri-Lanka), [80](https://github.com/nicolasize/Awesome-Sri-Lanka)]. More concretely, projects like the CSE data fetcher [[63](https://github.com/heyisula/cse-unofficial-api-data-pipeline)], the MOH scraper [[53](https://github.com/sudeepaviraj/administrative-api-srilanka/blob/main/DataScrape.py)], and the `srilanka-lottery` package [[55](https://github.com/Ishanoshada/Srilanka-Lottery/releases)] showcase a high degree of technical sophistication within the local tech scene. These grassroots efforts are arguably more effective at uncovering "hidden" APIs than any top-down government initiative. They prove that innovation in Sri Lanka is not solely top-down but is also driven from the bottom up by passionate individuals responding to real-world needs.

Thirdly, the analysis confirms that the API ecosystem in Sri Lanka is intensely mobile and location-centric. The strategic importance of Dialog Axiata's Ideamart/Ideabiz platform cannot be overstated; it provides developers with unprecedented access to carrier-grade infrastructure, enabling a new class of location-based and carrier-aware services [[155](https://www.dailymirror.lk/print/ict/Hutch-expands-Ideamart-subscriber-reach/269-114105), [165](https://ideamart.lk/), [166](https://docs.ideabiz.lk/Tips/IdeamarttoIdeaBiz/)]. The parallel launch of similar APIs for OTP, device location, and carrier billing by SLT-Mobitel reinforces this trend [[65](https://dialog.lk/news/sri-lankas-four-mobile-operators-commercially-launch-country-wide-network-apis)]. This suggests that any application aiming to succeed in the Sri Lankan market must consider the mobile context and explore integration with telecom providers for enhanced functionality and user trust. Complementing this is the recurring importance of geospatial data. From transport networks to irrigation levels, GIS data forms a foundational layer upon which much of the country's digital economy is built [[23](https://gisapps.nsdi.gov.lk/server/rest/services/Srilanka/Transport/MapServer/layers), [36](https://github.com/shakee93/sl-water-levels), [40](https://gisapps.nsdi.gov.lk/server/rest/services/SLNSDI/Utilities_Communications/MapServer/27)]. Its availability through open ArcGIS services lowers the barrier to entry for developers working in logistics, agriculture, disaster management, and urban planning.

Based on these synthesized insights, a strategic approach to leveraging APIs in Sri Lanka should be multifaceted:

1.  **Adopt a Layered Discovery Strategy:** Developers should not rely on a single source. The optimal approach involves starting with the most reliable but potentially restrictive official channels, such as the Sri Lanka DPI Developer Portal [[188](https://docs.dev.digieconcenter.gov.lk/docs/changelog)]. This should be supplemented by engaging with commercial data aggregators like NewsData.io for broad news coverage [[41](https://newsdata.io/)] and local service providers like Text.lk for SMS and communication services [[132](https://text.lk/)]. Crucially, this strategy must include a persistent search of community resources on GitHub and developer forums for niche, unofficial APIs that offer unique data in local languages or for specific domains [[45](https://github.com/tharustack/Hiru-News-API), [55](https://github.com/Ishanoshada/Srilanka-Lottery/releases)]. Finally, for truly novel or undocumented data, developers must be prepared to employ reverse-engineering techniques, such as proxying mobile app traffic with tools like Charles Proxy [[91](https://www.davidxia.com/2020/10/how-to-analyze-mobile-app-traffic-and-reverse-engineer-its-non-public-api/), [93](https://medium.com/@rehmat_87380/reverse-engineering-mobile-apps-to-open-new-doors-of-data-9d8f7e01ac53)], as demonstrated by the successful discovery of the CSE and MOH APIs [[53](https://github.com/sudeepaviraj/administrative-api-srilanka/blob/main/DataScrape.py), [63](https://github.com/heyisula/cse-unofficial-api-data-pipeline)].

2.  **Prioritize Security and Authentication:** The API landscape is populated with a variety of authentication mechanisms. While newer government and commercial platforms increasingly adopt modern standards like OAuth2 [[166](https://docs.ideabiz.lk/Tips/IdeamarttoIdeaBiz/)] and Bearer Tokens [[207](https://text.lk/docs/textlk-ios-swift-integration/)], many older systems rely on simpler methods like session cookies and headers [[63](https://github.com/heyisula/cse-unofficial-api-data-pipeline)]. The discovery of unsecured endpoints [[53](https://github.com/sudeepaviraj/administrative-api-srilanka/blob/main/DataScrape.py)] serves as a critical warning that extra diligence is required when handling sensitive data, and that assumptions about security should never be taken for granted.

3.  **Focus on High-Potential Sectors:** The analysis identifies several sectors where API-driven innovation holds significant promise:
    *   **Agriculture and Disaster Management:** By combining the open, real-time river gauge data from the Department of Irrigation [[36](https://github.com/shakee93/sl-water-levels)] with machine learning models for flood prediction [[37](https://github.com/hm7mihiranga/AI-powered-flood-and-weather-prediction-model-for-Sustainable-development-in-Sri-Lanka)] and weather forecasts from APIs like OpenWeatherMap [[37](https://github.com/hm7mihiranga/AI-powered-flood-and-weather-prediction-model-for-Sustainable-development-in-Sri-Lanka)], developers can create life-saving flood alert systems.
    *   **Finance and Investment:** The reverse-engineered CSE API provides a foundation for building market intelligence dashboards and analytical tools for retail investors [[63](https://github.com/heyisula/cse-unofficial-api-data-pipeline)]. The upcoming Open Banking framework from the CBSL promises to unlock even more potential for fintech innovation [[197](https://www.cbsl.gov.lk/sites/default/files/cbslweb_documents/about/central_banks_policy_agenda_for_2026_and_beyond_e.pdf)].
    *   **Logistics and Transportation:** Integrating GIS data from the Ministry of Transport [[23](https://gisapps.nsdi.gov.lk/server/rest/services/Srilanka/Transport/MapServer/layers)] with the NWSDB's payment verification API [[39](https://www.waterboard.lk/agreement-signed-to-install-paygo-kiosk-machines-at-battaramulla-and-mattakkuliya-offices/)] could lead to the development of seamless logistics and utility management platforms.
    *   **Tourism:** Leveraging global travel APIs from Booking.com and Expedia [[83](https://developers.booking.com/), [84](https://developers.expediagroup.com/)] and combining them with local data from the SLTDA [[50](https://www.sltda.gov.lk/en/statistics)] and real-time news feeds can create highly personalized and context-aware travel recommendation engines.

In summation, the API ecosystem of Sri Lanka is a frontier of immense potential, characterized by both official progress and hidden opportunities. Success in navigating this landscape requires a blend of formal engagement, community collaboration, and investigative prowess. The journey to discover and utilize these APIs is not merely a technical exercise but a reflection of the country's broader transition into a digital economy.

# The Sri Lanka API & Data Directory: An Exhaustive, Sector-by-Sector Map

## TL;DR
- **There is no single "Sri Lanka API" ecosystem — the landscape is a patchwork of a handful of genuinely open/official APIs (data.gov.lk CKAN, PayHere/OnePay payments, Ideamart/IdeaBiz telecom, SMS gateways, the srilanka-holidays API, Daraz Open Platform), a large body of community/open-source datasets and reverse-engineered endpoints (most famously the unofficial Colombo Stock Exchange `cse.lk/api/`), and many sectors with NO API at all where the only workaround is scraping or a global API filtered to `country=LK`.**
- **The most useful live, verifiable APIs are: the CSE unofficial endpoints (POST, no auth), data.gov.lk & data.health.gov.lk CKAN, PayHere/OnePay/WebXPay payment gateways, Text.lk/Notify.lk/Ideamart SMS & telecom, NewsData.io/GDELT for news with LK filters, srilanka-holidays.vercel.app, and rich community datasets (postal codes, NIC parsers, admin boundaries) on GitHub/npm/PyPI.**
- **Flag hard: reverse-engineered endpoints (CSE, doenets exam results, courier tracking) carry ToS/stability risk and can break without notice; several once-promoted APIs are dead (ICTA train-schedule JSON API, COVID-era HPB endpoints); and all bank/LankaPay payment rails are B2B-only with no public sandbox.**

## Key Findings
- **Government open data is real and CKAN-based.** `data.gov.lk` and `data.health.gov.lk` both run CKAN with standard `/api/3/action/package_list` endpoints and `data.json` catalogs. The Department of Agriculture advertises a keyed REST API at `api.doa.gov.lk/v1`.
- **Payments are the most mature commercial API sector.** PayHere is the dominant, well-documented gateway (Checkout, Recurring, Preapproval, Charging, Retrieval, Subscription Manager, Refund, Authorize, Capture APIs + JS/Android/iOS/React Native/Flutter SDKs). OnePay (REST v3, JSON, SHA-256 signed, ISO 27001), WebXPay, DirectPay, and Genie Business are live alternatives. Bank IPGs and LankaPay rails exist but are B2B-only — no public sandbox.
- **The CSE "API" is unofficial but heavily used.** `https://www.cse.lk/api/` exposes ~20 POST endpoints. The documentation repo GH0STH4CKER/Colombo-Stock-Exchange-CSE-API-Documentation states plainly that these were "reverse-engineered since no official documentation exists," base URL `https://www.cse.lk/api/`, all endpoints POST, no auth. It is wrapped by at least two CSE MCP servers.
- **Telecom is unusually rich.** All four operators launched GSMA Open Gateway (CAMARA) APIs; Dialog's Ideamart/IdeaBiz platform offers SMS, USSD, Charging-as-a-Service, Subscription, and Location APIs with full docs. Independent SMS gateways (Text.lk, Notify.lk) offer clean REST APIs with published pricing.
- **Community/open-source fills most gaps.** Excellent free resources exist for holidays (Dilshan-H/srilanka-holidays), postal codes & cities (madurapa), NIC validation (npm `@sri-lanka/nic`, Go, Python, PHP), Sinhala NLP (HuggingFace models, SinLlama), and admin boundaries (HDX/GADM).
- **Dead/deprecated:** the ICTA train-schedule JSON API is no longer public; COVID-era HPB endpoints are defunct; the meteorology department has no documented public API.

## Details by Sector

### 1. News & Media
- **RSS is the workhorse.** Nearly every major outlet publishes RSS: **Ada Derana** (`adaderana.lk/rss.php`), **Daily Mirror** (`dailymirror.lk/rss` and `dailymirror.lk/index.php?format=feed&type=rss`), **EconomyNext** (`economynext.com/feed`), plus News.lk, Onlanka, Lanka Business Online, ITN News, Dinamina, Newsfirst, The Island, Sunday Observer, Virakesari, Lankadeepa, Lanka Puvath, Uthayan, Nation.lk, Silumina, Ravaya, and more. FeedSpot catalogs 30–45 Sri Lanka feeds. Format: RSS/XML; no auth; free; liveness good (feeds actively updated 2026). ToS: personal/aggregation use generally OK — check each outlet.
- **Central Bank RSS:** `cbsl.gov.lk/en/rss-feeds` (Monetary Policy Review, Weekly/Monthly Economic Indicators, Notices).
- **Global news APIs with LK filters (official, keyed):**
  - **NewsData.io** — `newsdata.io/api/1/latest?country=lk&apikey=...`; freemium; REST/JSON.
  - **APITube** — Sri Lanka news search, historical data from 1998, JSON/XML/CSV, sentiment; freemium.
  - **GDELT** — free, no key, global event/news database queryable by country=Sri Lanka; REST/JSON.
  - Others applicable: NewsAPI.org, GNews, Mediastack, Webz.io — all support a Sri Lanka/`lk` filter; freemium/paid.
- **Community:** CeylonNews (trilingual news reader), topjobs-scraper — open-source on GitHub.

### 2. Government & Open Data
- **data.gov.lk** — Official national open data portal (CKAN). Endpoints: `data.gov.lk/api/3/action/package_list`, catalog `data.gov.lk/data.json`. Coverage: agriculture, demography, economy, transport, IT, cybersecurity. Format: CKAN REST/JSON; no auth for reads; free.
- **data.health.gov.lk** — Ministry of Health open data (CKAN). `data.health.gov.lk/api/3/action/package_search` and `.../package_list`. Free, CKAN/JSON.
- **api.doa.gov.lk/v1** — Department of Agriculture REST API (crop data, ag statistics, weather). Auth: API key (`?access_key=`). Example: `api.doa.gov.lk/v1/crops?access_key=YOUR_KEY`. Provider: official. (Uptime unverified — confirm before depending on it.)
- **Department of Census & Statistics** — `statistics.gov.lk`; "Lanka Datta" microdata catalog for research; Census 2024, economic census, household surveys. Mostly dataset downloads, not a live API.
- **Humanitarian Data Exchange (HDX)** — `data.humdata.org/group/lka`; the HDX Sri Lanka group page states you can "Access 128 humanitarian datasets for Sri Lanka from 43 organizations on HDX." HDX runs CKAN, so `/api/3/action/...` works; free.
- **IOM Displacement Tracking Matrix** — `dtm.iom.int/sri-lanka`; mobility/demographic data; dataset + API access.
- **Upcoming/announced:** cross-government API policies and FAO-collaboration Agriculture Enterprise Architecture APIs (noted as in development — not yet live; treat as forward-looking).
- **Gaps:** Gazette/legal data, Parliament data, Election Commission results — no official API; community election datasets appear on GitHub; workaround is scraping.

### 3. Finance & Payments
- **PayHere** (official; Central Bank-approved aggregated IPG). Docs at `support.payhere.lk`. APIs: Checkout (live `payhere.lk/pay/checkout`, sandbox `sandbox.payhere.lk/pay/checkout`), Recurring, Preapproval, Charging, Retrieval, Subscription Manager, Refund, Authorize, Capture. SDKs: JS, Android, iOS, React Native, Flutter. Plugins: WooCommerce, Magento, OpenCart, PrestaShop, Shopify, ShopHere, WHMCS, CS-Cart. Auth: Merchant ID + Merchant Secret + MD5 hash; server callback (`notify_url`). Currencies: LKR, USD, EUR, GBP, AUD. Pricing: per-transaction fee, no monthly. Requires a Sri Lankan business account. Community SDKs: `lahirulhr/laravel-payhere` (Packagist), `dasunNimantha` Node.js integration. Live 2026.
- **OnePay** (official; ISO 27001-certified, first in SL). Docs `docs.onepay.lk/api-documentation`. REST v3, JSON, SHA-256 signed requests, sandbox available; LKR & USD; SDKs/plugins in PHP/Node/Python/Java/.NET. Wraps LankaPay JustPay/CEFTS/LankaQR for merchants.
- **WebXPay** (official; "Made in Sri Lanka"). 13+ payment options (Visa, Mastercard, UnionPay, Amex, Discover, Diners, eZ Cash, mCash, Sampath Vishwa, FriMi, Upay, Genie, DFCC wallet). Multi-currency (LKR/USD/EUR/GBP/AUD), T+1 settlement, recurring billing, LankaQR/UPI/Alipay+ bridge, PCI-DSS/ISO 27001 via partner banks. Plugins for Magento/Shopify. Merchant onboarding required.
- **DirectPay** — SL fintech; IPG + payment links + mobile app; modern APIs, low fees, fast settlement.
- **Genie Business (Dialog)** — QR + IPG; strong for retail; low QR fees. Also **Payzy** (BNPL), **PAYable**, **Mintpay**.
- **LankaPay / LankaClear (JustPay, CEFTS, LankaQR)** — National payment rails, CBSL-supervised. **No public developer portal or open API** — B2B only, integration via LankaClear member onboarding and vendor connectors (Epic Lanka eConnector, Fortunaglobal). Low-level ISO 8583/20022, PKI (LankaSign). JustPay is a "slab based, extremely low tariff scheme"; CEFTS per-transaction max Rs. 5 million. Consumer access only via licensed intermediaries (e.g., Onepay). Live infrastructure.
- **Bank IPGs** (all official, all merchant-onboarding-only, no public sandbox):
  - **Sampath Bank** Vishwa/PayCorp IPG — `sampath.lk`; contact ipg@sampath.lk; community SDK `pnm1231/paycorp-sampath-ipg` (Laravel/Packagist), WordPress plugin, Magento 2 extension. Auth: Client ID + Customer ID + Auth token + HMAC.
  - **Commercial Bank (ComBank) "SimplePay" IPG** — `combank.lk/services/internet-payment-gateway`; backend Mastercard Payment Gateway Services (MPGS) + Visa Cybersource, tokenization, 3DS, multi-currency.
  - **HNB IPG** — `hnb.lk/sme-banking/e-business-solutions/hnb-payment-gateway`; CyberSource backend; provides Java/ASP.NET/PHP dev materials to merchants; notably allows donations (non-profits).
  - **BOC** — IPG hosted on MPGS; onboarding via BOC Card Centre.
  - **NDB "NEOS"** — consumer mobile banking app (JustPay/LankaQR "Neos Pay"), NOT a developer API.
  - **Seylan** — merchant IPG, third-party plugins; no public portal. **People's Bank** — no public IPG developer docs located (gap).
- **Mobile wallets:** eZ Cash (Dialog), mCash (Mobitel), FriMi, Genie, iPay, Q Plus — mostly accessed via aggregators (PayHere/WebXPay) rather than direct public APIs; Dialog eZ Cash has a WooCommerce gateway (`madurapa/woocommerce-ezcash`).

### 4. Stock Market & Economy
- **Colombo Stock Exchange unofficial API** — `https://www.cse.lk/api/` (base). All endpoints are **POST**, `application/x-www-form-urlencoded`, JSON responses, **no auth**. Endpoints: `marketSummery`, `aspiData`, `snpData`, `chartData` (symbol, chartId, period), `allSectors`, `detailedTrades`, `dailyMarketSummery`, `companyInfoSummery` (symbol), `tradeSummary`, `todaySharePrice`, `topGainers`, `topLooses`, `mostActiveTrades`, `getNewListing`, `companyChartDataByStock` (stockId, period). Documented by **GH0STH4CKER/Colombo-Stock-Exchange-CSE-API-Documentation**, which describes the endpoints as "reverse-engineered since no official documentation exists" (with Python examples). **Unofficial/reverse-engineered** — ToS & stability risk; can break/rate-limit without notice.
- **CSE MCP servers** — `Shaveen12/cse-mcp` (npx `cse-mcp`, 308-company DB, fuzzy search, real-time price) and a Gajarthan MCP server (search companies, quotes, market snapshot, gainers/losers). Community; free.
- **Licensed CSE feeds** — **ICE Consolidated Feed** (developer.ice.com) offers normalized Level 1 CSE market data via enterprise API; paid/licensed. **EODHD** lists Colombo exchange ("CM") end-of-day data via paid subscription.
- **Central Bank of Sri Lanka (CBSL)** — Economic Data Library, rates & indicators pages; exchange rates at `cbsl.gov.lk/cbsl_custom/exrates/exrates.php` and `.../en/rates-and-indicators/exchange-rates`. Mostly web pages + downloadable XLSX + RSS; no official REST API.
- **Fluentax CBSL Exchange Rates API** — third-party commercial API delivering official CBSL daily LKR rates in a developer-friendly form for ERP/tax systems. Not affiliated with CBSL.
- **World Bank / IMF / ADB** — all offer official APIs filterable to `LKA`/Sri Lanka (World Bank Indicators API is free, REST/JSON, no key).

## Notable Gaps & Best Workarounds
- **Weather:** No official meteo API → use Open-Meteo (free) / OpenWeatherMap for LK coordinates.
- **Tourism stats (SLTDA):** No API → scrape monthly PDFs or use dashboards.
- **Fuel prices (CEYPETCO/LIOC):** No API → scrape.
- **Power cuts (CEB):** No open API → scrape CEBCare/PDFs (2022-era community APIs mostly dead).
- **Rail/bus schedules:** ICTA API dead → scrape `eservices.railway.gov.lk` or use community sites; no official GTFS.
- **Government legal/gazette/parliament/elections:** No APIs → scrape or use community datasets.
- **Company registry / IRD / EPF-ETF / Customs / Survey Dept:** e-services only, no APIs.
- **Classifieds (ikman) & food delivery:** No public APIs → scraping (ToS risk).

## Recommendations
1. **Start with the official, keyed/free APIs for anything production-critical:** data.gov.lk & data.health.gov.lk (CKAN), PayHere or OnePay (payments), Text.lk/Notify.lk or Ideamart (messaging), Daraz Open Platform (marketplace), ReliefWeb (disaster), World Bank (economy), srilanka-holidays (calendar). These have documentation, some form of auth/SLA, and are actively maintained.
2. **Treat the CSE `cse.lk/api/` endpoints, doenets exam-results wrappers, and courier-tracking aggregators as convenience-only / prototyping tools.** They are unofficial/reverse-engineered — build a scraping fallback, cache aggressively, and never rely on them for compliance-grade or SLA-bound use. Monitor the source repos' last-commit dates.
3. **For sectors with no API (weather, tourism stats, fuel, power cuts, gazette/legal, company registry), default to a two-tier approach:** (a) a reputable global API filtered to `country=LK`/`LKA` where one exists (weather, biodiversity, flights, cricket, places), and (b) a resilient scraper with change-detection where only a government web portal exists.
4. **For payments, decide by audience:** local-customer storefronts → PayHere (largest base, best plugins) or OnePay (ISO 27001, clean REST v3); QR/retail → Genie Business; if you need direct bank settlement, expect a merchant-onboarding process and privately-issued docs (no sandbox). Do not expect to self-serve LankaPay/CEFTS — go through a licensed aggregator (e.g., OnePay).
5. **Benchmarks that should change your choice:** if an unofficial endpoint's backing GitHub repo has no commits in 12+ months or its docs 404, migrate off it. If a global API's free tier rate limit (e.g., NewsData.io, cricket APIs) throttles you, move to the paid tier or self-host (GDELT, Open-Meteo have generous free access). For Sinhala NLP, prefer SinLlama/Sinhala-BERT if you can self-host; use Google/Azure/Lingvanex when you need managed TTS/STT/translation SLAs.

## Caveats
- **Liveness is a moving target.** Where I could verify (CSE endpoints, PayHere/OnePay docs, Text.lk/Notify.lk, data.gov.lk CKAN, srilanka-holidays, Daraz Open Platform, ReliefWeb, CBSL exchange pages), items are live as of mid-2026. Government endpoints in particular change without notice.
- **Unofficial/reverse-engineered APIs carry legal & stability risk.** The CSE API, doenets exam wrappers, courier-tracking scrapers, and any ikman/Kapruka scrapers are not sanctioned; using them may violate site ToS and they can break or rate-limit at any time.
- **Dead/deprecated confirmed:** ICTA train-schedule JSON API (repo README confirms it's gone), HPB COVID-19 endpoints (legacy), and various 2022 load-shedding community APIs.
- **Bank/LankaPay rails are B2B-only.** "Easy integration" language on bank sites is marketing; real docs are merchant/NDA-only, with no public sandbox. People's Bank IPG developer documentation could not be located.
- **The `api.doa.gov.lk` Department of Agriculture API** is advertised in the community directory with a keyed example, but I could not independently verify its current uptime — confirm before depending on it.
- **Minor figure conflicts to note:** Ideamart's revenue-share is stated as 50/50 on its own docs but 70% appears on IdeaBiz docs; HDX dataset counts drift over time (currently 128/43 orgs vs. 133+ cited in the community directory). Always re-verify the endpoint, auth, pricing, and ToS directly with the provider at implementation time for any high-stakes integration.
